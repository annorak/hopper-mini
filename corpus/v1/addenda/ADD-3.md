# ADD-3 Bayview Pump Station Upgrade

Addendum issue order 3. Read each item with SPEC-01/1.2.

## 1 Station reliability run

Revise SPEC-17/3.1. Replace the stated requirement with the following requirement.

The station reliability-run duration is 72 hours.

Use the revised continuous operating period after the accepted site functional test. Existing failure and restart rules remain in force.

## 2 Operator training duration

Revise SPEC-19/3.1. Replace the stated requirement with the following requirement.

The required operator training duration is 8 hours.

Include additional practical instruction on drive recovery and alarm handling. Deliver the training using the accepted station manuals.

## 3 Spare intake-screen sets

Revise SPEC-20/3.2. Replace the stated requirement with the following requirement.

The spare ventilation intake-screen set quantity is 2.

Identify each packaged set in the spare-part register. Supply-air filters remain a separate consumable item.
