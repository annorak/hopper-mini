# ADD-2 Bayview Pump Station Upgrade

Addendum issue order 2. Read each item with SPEC-01/1.2.

## 1 Drive enclosure rating

Revise SPEC-11/2.1. Replace the stated requirement with the following requirement.

The pump-drive enclosure rating is NEMA 4X.

Use an enclosure suitable for the owner washdown procedure. Cable entries and accessories shall maintain the revised rating.

## 2 Telemetry alarm delay

Revise SPEC-13/2.2. Replace the stated requirement with the following requirement.

The telemetry alarm transmission delay is 30 seconds.

Start this interval after the controller declares the alarm active. The common input debounce and local horn delay are unchanged.

## 3 Epoxy dry-film thickness

Revise SPEC-16/2.1. Replace the stated requirement with the following requirement.

The completed epoxy dry-film thickness is 350 micrometres.

Submit the revised application schedule and inspection target. The theoretical single-coat coverage allowance is unchanged.
