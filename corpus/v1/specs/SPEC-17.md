# SPEC-17 Testing and commissioning

Bayview Pump Station Upgrade | Contract specification

## 1.1 Commissioning sequence

Complete dry checks, wet duty tests, integrated control tests, and the reliability run in that order. Do not use the reliability run to discover unfinished basic wiring. The commissioning coordinator shall maintain the deficiency register and confirm closure before the next test stage begins.

## 1.2 Factory test allowance

The factory witness-test duration is the allowance shown on the general drawing. The site functional-test allowance is a separate activity. Use both allowances for witness staffing plans. Supplier preparation and travel are outside the witness-test duration and remain the supplier responsibility.

## 2.1 Site test allowance

The site functional-test duration is 24 hours. This allowance covers the witnessed functional test after dry checks are complete. It excludes the subsequent reliability run. Submit an agenda that gives the owner time to witness pump transfer, alarm handling, and restoration after simulated failures.

## 2.2 Test instrumentation

Use calibrated portable instruments for witnessed flow, pressure, current, and vibration readings. Identify calibration records on the test sheet. Permanent instruments may provide supporting trends but do not replace the portable reference where the test procedure calls for one. Record the operating configuration with each reading.

## 2.3 Test failures

Stop a test when leakage, abnormal vibration, or a protective trip threatens equipment or service. Log the failure and retain the partial results. Correct the cause, agree the restart point with the owner, and repeat the affected test. Do not erase a failed test record after a successful repeat.

## 3.1 Reliability run

The station reliability-run duration is 48 hours. Start the run after the owner accepts the site functional-test results. Maintain automatic duty transfer and alarm reporting throughout the run. An equipment failure that interrupts required station operation restarts the run after the defect is corrected.

## 3.2 Commissioning record

Compile signed test sheets, final settings, deficiency closure evidence, and the accepted program revision in the commissioning record. The owner acceptance signature shall identify the equipment and functions accepted. Carry deferred seasonal checks as named open items with the agreed conditions for completion.
