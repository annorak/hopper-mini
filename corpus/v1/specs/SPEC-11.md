# SPEC-11 Motor controls, drives, and backup power

Bayview Pump Station Upgrade | Contract specification

## 1.1 Control arrangement

Provide a separate variable-frequency drive for each permanent pump. The drive panel includes isolators, motor protection, local control, and status contacts to the station controller. Keep the drive cooling path separate from the cable entry area. The supplier shall coordinate drive and motor protection as one package.

## 1.2 Shelf spare drive

The shelf spare drive count is 1. Supply the spare with the same hardware rating and accepted parameter file as an installed pump drive. Store it in sealed packaging with the owner inventory tag. The spare is not an additional installed operating drive.

## 2.1 Drive enclosure

The pump-drive enclosure rating is NEMA 12. Locate the panels in the control room and provide a continuous protective-earth bar. Keep control wiring segregated from drive output conductors. The enclosure shall retain its specified rating after cable glands and ventilation accessories are installed.

## 2.2 Drive setup

Set acceleration, deceleration, and speed limits to the accepted hydraulic operating range. Save the final parameter file after the site duty test. Provide the owner with the manufacturer software needed to restore that file. Mark parameters that differ from the supplier standard configuration.

## 2.3 Backup energy

The usable control backup energy is 1200 Wh. This value is the accepted usable energy at the backup unit output under the commissioning condition. The backup system supports controls and telemetry only. Pump motors and ventilation equipment remain outside the backed-up load group.

## 3.1 Backed-up load

The control and telemetry backup load is 200 W. Include the station controller, local interface, communications unit, and essential instrument supplies in this load. Measure the load with the accepted configuration running. Provide a low-battery alarm before the backup unit reaches its shutdown state.

## 3.2 Drive functional test

Demonstrate local isolation, drive fault indication, controlled stop, and restart after a cleared fault. Verify that a removed local-control key prevents remote operation where the selector requires it. Record the final parameter checksum in the acceptance package. Keep a paper recovery procedure inside the drive-panel document pocket.
